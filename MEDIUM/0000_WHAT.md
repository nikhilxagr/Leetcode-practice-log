## 💡 Common Patterns

<div style="background: linear-gradient(135deg, #FA8BFF 0%, #2BD2FF 100%); padding: 15px; border-radius: 8px; color: white; margin: 10px 0;">

Medium array problems typically involve:

</div>

1. **🪟 Sliding Window** - Dynamic window for subarrays
2. **👉👈 Two Pointers** - Start and end pointer manipulation
3. **✂️ Divide and Conquer** - Breaking problems into subproblems
4. **💾 Dynamic Programming** - Optimal substructure problems
5. **📊 Prefix/Suffix Arrays** - Precomputation for efficiency
6. **🔍 Binary Search** - On sorted or partially sorted arrays

## 🎯 Tips for Success

> **Pro Tips from Nikhil Agrahari**

- 📊 **Visualize** - Draw out examples to see the pattern
- 🔍 **Pattern Recognition** - Look for patterns in test cases
- ⚡ **Optimize Early** - Think about optimization from the start
- 🧪 **Edge Cases** - Test duplicates, negatives, sorted arrays
- 📝 **Pseudocode** - Write pseudocode before implementing
- 🎨 **Multiple Approaches** - Consider different solutions
- 🕐 **Time Yourself** - Practice under time constraints
- 🔄 **Review** - Learn from editorial solutions
