## 💡 Common Patterns

<div style="background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%); padding: 15px; border-radius: 8px; color: white; margin: 10px 0;">

Easy array problems typically involve:

</div>

1. **🔄 Linear Traversal** - Single pass through the array
2. **👉👈 Two Pointers** - Using two indices to traverse
3. **🗺️ Hash Maps** - For O(1) lookups
4. **📊 Frequency Counting** - Tracking element occurrences

## 🎯 Tips for Success

> **Pro Tips from Nikhil Agrahari**

- 📖 **Read Carefully** - Understand the problem statement thoroughly
- 🧪 **Test First** - Always test with sample inputs before submission
- ⏱️ **Optimize Later** - Start with brute force, then optimize
- 💬 **Comment Well** - Add comments to explain your logic
- 🔍 **Edge Cases** - Consider empty array, single element, duplicates
- 🎨 **Code Quality** - Write clean, readable code
